# Yard Queue

Phone-first player for the Support Process Audit yard-work listening queue.

The Google Drive folder is private, so this page does not stream those MP3s by itself. Download the folder to your phone, open this player, tap **Load audio from phone**, then add the page to your Home Screen.

## Enable GitHub Pages (one time)

Repo Settings → Pages → Deploy from branch → `main` / `/ (root)`.
Then the phone URL is:

https://gatewooddynomite.github.io/yard-work-podcast-player/
